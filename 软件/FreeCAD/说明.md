# FreeCAD：怎么连

- **验证过的版本**：FreeCAD 1.1.4（Windows x64，便携版也行）。
- **原理**：`fc_link.py` 在 FreeCAD 前台窗口里起一个 0.2 秒的界面线程定时器，查 `运行数据\FreeCAD\inbox\`，执行命令、重算、刷新视图，把实读结果写回 `outbox\`。不开网络端口。
- **一键连接**（`<本包>` 换成本包绝对路径）：
  ```
  powershell -NoProfile -ExecutionPolicy Bypass -File "<本包>\软件\FreeCAD\连接程序\一键连接.ps1"
  ```
  须出现 `RESULT: OK`。已连上会直接沿用，不开第二个。找不到软件就加 `-FreeCAD <FreeCAD.exe 路径>`。
  软件用 WMI 脱离 Agent 启动，命令结束窗口不会被带走，不用自己写保活脚本。界面默认中文（配置在本包 `运行数据\FreeCAD用户\user.cfg`，不动本机原有设置；要英文就启动前设 `NGXZ_FC_LANG=English`）。
- **发命令**：`powershell -NoProfile -ExecutionPolicy Bypass -File "<本包>\软件\FreeCAD\连接程序\fc.ps1" <命令> key=value …`，下文简写 `fc`。
  - `fc status`，看文档、对象名和实读。
  - `fc box L=100 W=50 H=30`，建方块。`fc set obj=Box prop=Height value=60` 改尺寸。
  - `fc cyl D=19 H=1.5`，建圆柱；`fc hole D=10 x=40 y=40`，打通孔（`obj=` 指定对象）。
  - `fc chamfer size=1 edges=top`，倒角；`fc fillet size=2 edges=vertical`，倒圆。edges 可选 top、bottom、vertical、outer、inner、circle、all，或编号 `3,5`，用 `+` 连接。
  - `fc measure bbox=100,50,60 faces=6`，实读并核对。返回包围盒、体积、面数、内孔/外圆直径、锥面（倒角，含径向/轴向尺寸）和平面位置。
  - `fc dim n=1 kind=dia D=19 at=0,15,0`，在模型上标直径，软件从圆棱实测，标注文字是 `⌀$dim (1)`（$dim 是软件实时量的值；目前视图里显示带单位和两位小数，如 `⌀19.00 mm (1)`）；`fc dim n=3 p1=… p2=… at=…` 标两点距离（点从 measure 结果取）。回包里的「实测」就是软件量出来的值。
  - `fc py 脚本.py D=19`，复杂形状在前台跑 Python。脚本里可以用 App、Part、doc、measure、refresh，结果放 `result`。
  - `fc undo` 撤回，`fc clear` 清空，`fc save path=…FCStd` 存盘，`fc shot path=…png` 截视图。
  - `fc step path=成果\<任务名>\<零件名>.step` 导出 STEP（`fc save path=….step` 或 `.stp` 同效），只导出可见实体；回包里「读回体积」和「模型体积」一致才算导出成功。成果统一交 STEP。
  - `fc exp_search q=短词`、`exp_done`、`exp_save`、`exp_list`，搜经验和存经验。
- **怎么判断连上了**：`fc wait` 打印 `CONNECTED FreeCAD 1.1.4 pid=…`，YA 显示「已连接」。
- **易卡点**：
  - 首次启动要 10 到 40 秒，`wait` 会自己等。
  - 用户配置放在 `运行数据\FreeCAD用户\`，不动本机原有的 FreeCAD 设置。
  - 命令超时多半是前台弹了对话框，先看窗口。
  - 圆柱求差后，原对象会被隐藏，`obj=` 要用新对象名（看回包里的「新对象」）。
- **经验**：在 `经验\`，用 `索引.json` 检索，一行一条；`_草稿\` 里放没验证过的。
