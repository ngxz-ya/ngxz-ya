# 连接教练

首连请直接看 [通用接入指南](通用接入指南.md)。本目录其他页面用于维护经验和旧教练台账。包根统一入口按软件名查已有经验和环境；Agent研究本机方法，按适配器协议执行任务；它不把批处理标为常驻连接。本目录不独立扫描机器软件。

| 文件 | 作用 |
| --- | --- |
| `三步闸.md` | 搜公开资料、试挂、小任务过关。过关才写入已挂 |
| `提示模板.md` | 交给任何 Agent 的提示。含先检索、自检、验收、打回、举手 |
| `自检清单.md` | 五项。少一项就不能报完成 |
| `连接经验\` | 「连××软件」的调用与存储（跨软件通用）：`连接经验.ps1 find` 先查卡，连上后按 `说明.md` 模板写连接卡 `add`；每槽一个子目录 |

使用者只连接自己已经合法安装的软件。只找合法连接途径、不侵权；软件支持清单和适配器须准确写明产品与版本；通用协议不写产品专属分支。

看现在挂上了谁：

```
powershell -NoProfile -ExecutionPolicy Bypass -File ".\YA插件\本包命令.ps1" link_list
powershell -NoProfile -ExecutionPolicy Bypass -File ".\YA插件\本包命令.ps1" overview
```
