# Agent 提示模板

日常首连只需仓库地址和软件名。Agent 从根目录读 AGENTS.md，运行启动入口，再按 [通用接入指南](通用接入指南.md) 完成核验。

起始目录已经有本包和经验就直接用，不要重新下载、不要另解一份覆盖已有经验。

连接成功要看到目标窗口、在同一可见会话操作并读回、由 YA 完成登记与验收。缺少前台通道时说明阻塞。只有用户明确要求后台执行才使用 Run -AllowBatch。

已有任务和经验原样保留。旧教练台账按 [三步闸](三步闸.md) 维护，工程任务的自检见 [自检清单](自检清单.md)。这些记录可以帮助排查，连接状态以本次软件与 YA 回执为准。
