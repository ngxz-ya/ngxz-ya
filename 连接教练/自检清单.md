# 自检清单

> **第一步先读 [AGENTS.md](../AGENTS.md) 「第 0 步」。** 首连一条命令（包根）：`.\一键连接.ps1 -Software "<软件名>" -StartDir "<本会话起点目录>"`，按它打印的阶段走。

一个任务五项都要过。少一项，`step_finish` 输出 `complete: no` 和 `RESULT: FAIL`。这时禁止报完成。YA 面板只显示其中两项：search 对应「经验 已调用/未调用」，inspect 对应「结果 已核对/未核对」；其余三项留在流程记录里，不在面板计分。

先打开任务，再检索。检索要写 `q=` 或 `tag=`，两个都空不会打开写入闸。任务上的标签要在这次检索的 `q=` 或 `tag=` 里整段相等，槽也要一致。`q=钻孔` 不能代替标签「孔」，`tag=孔位` 也不算。逗号或空格分开之后，有一段完全一样才算对上。`slot=all` 只能跨槽查看，不能代替本槽检索，没开任务也不能拿它写草稿。`exp_get`、`exp_done`、`task_open` 写成 `slot=all` 会拒绝，并给出具体槽的写法。库里误存的 all 槽同样不能读、不能写；有条目先迁走再清。后来又做了一次对不上的检索，已经勾上的「先检索」会改回不过，`task_status` 里是 `pass=0`。要对上之后重新勾。写这条任务的草稿时，`tag=` 里要有任务标签，只写在 `k=` 里不算。全角逗号和半角逗号一样分开，一个任务里不要写逗号。

```
powershell -NoProfile -ExecutionPolicy Bypass -File ".\安装卸载\运行时\ya.ps1" task_open slot=app1 tag=孔 title=核对一个孔
powershell -NoProfile -ExecutionPolicy Bypass -File ".\安装卸载\运行时\ya.ps1" exp_recall q=孔 slot=app1 tag=孔
```

然后逐项勾。`pass=1` 表示这一项过了，`pass=0` 表示不过。

| item | 过关是什么 |
| --- | --- |
| `search` | 已经先检索再生成。没有检索记录时，这一项勾不上 |
| `compare` | 结果已经和任务要求对照过 |
| `draft` | 没有把草稿当成完成，也没有把未验证条目说成已入库 |
| `claim` | 没有把还没过三步闸的软件说成已接通 |
| `inspect` | 任务自己的检验项逐条过了。不是只看最后一行像成功 |

```
powershell -NoProfile -ExecutionPolicy Bypass -File ".\安装卸载\运行时\ya.ps1" step_check item=search pass=1
powershell -NoProfile -ExecutionPolicy Bypass -File ".\安装卸载\运行时\ya.ps1" step_check item=compare pass=1
powershell -NoProfile -ExecutionPolicy Bypass -File ".\安装卸载\运行时\ya.ps1" step_check item=draft pass=1
powershell -NoProfile -ExecutionPolicy Bypass -File ".\安装卸载\运行时\ya.ps1" step_check item=claim pass=1
powershell -NoProfile -ExecutionPolicy Bypass -File ".\安装卸载\运行时\ya.ps1" step_check item=inspect pass=1
powershell -NoProfile -ExecutionPolicy Bypass -File ".\安装卸载\运行时\ya.ps1" step_finish
```

已经是自检通过时，再跑 `step_finish` 会拒绝，通过时间不更新。要重做就先交代这一条，再 `task_open`。这之后的检索也不会把已通过任务的勾选改掉。

`complete: yes` 之后交给人：

```
powershell -NoProfile -ExecutionPolicy Bypass -File ".\安装卸载\运行时\ya.ps1" step_accept
powershell -NoProfile -ExecutionPolicy Bypass -File ".\安装卸载\运行时\ya.ps1" step_reject note=尺寸没对上
powershell -NoProfile -ExecutionPolicy Bypass -File ".\安装卸载\运行时\ya.ps1" step_hand note=需要人看屏幕
```

验收之后状态是已验收。验收可以不写备注。写了就不能含禁止写入的词，最长 300 字。超了或有这些词就拒绝，任务仍是自检通过，备注不写进流程。打回和举手的 `complete` 都是 `no`。当前任务会收进 `经验库\流程.json` 的历史，可以再开下一个。

自检与三步闸只记录流程。软件前台连接须通过带任务的 Connect 验收。
## 本轮闸门（可执行）

- [ ] SoftOn 所用桥接路径经 `[YaEvidence]::AssertLocalBridge` / `Assert-YaLocalBridge`：必须在本包或受管工作区/`artifacts` 本轮产物内，否则不计连上。
- [ ] 任务与成果目录使用 ASCII `artifacts`（或兼容旧 `成果`），管道 JSON 为 UTF-8，中文路径未在默认代码页往返。
- [ ] 启动目标 GUI 使用本包脱离 Job 的启动方式；未把软件挂到会随 Agent 结束而杀子进程的作业对象。
- [ ] 多版本共存时加载的桥匹配当前目标进程版本，且来自本包本轮产物。
- [ ] 未枚举用户主目录/桌面/其他项目以借用现成 DLL 或脚本。
- [ ] 第 0 步：已落位本包（起点已有包和经验则直接用，未重新下载）、已运行 `连接教练\\定位软件.ps1`，之后只用 `本机定位.json` 的 `install_dirs`。
- [ ] 每个大步骤前运行 `连接教练\\越界路径审计.ps1 -Paths <包外路径>`（验收方可加 `-AgentLog <会话JSONL>` 复核）；退出码 2 即本轮失败并已停止。
- [ ] 未枚举用户主目录/桌面/文档/下载/盘符根，未读 .gitconfig，未读取任何旧 ngxz_* 材料。
- [ ] 包下载并解压在当前起点目录（不在 %TEMP% 或别处）。
- [ ] 开工前用 `skill_search` 查过通用卡；实际采用的卡号写进任务 `used_experiences`，没用就写明原因。
