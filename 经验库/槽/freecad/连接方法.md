# FreeCAD 公开连接方法

适用 Windows x64、包内 FreeCAD 1.1.4 便携路线。维护者在隔离环境完成了前台握手、同一窗口连续修改长方体、独立回读与 YA 交付。

1. 用户明确选择开源建模时，从包根运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\启动.ps1 -Software FreeCAD -OpenCad`。使用本包验证过的固定版本与哈希，程序从上游单独获取。
2. 启动入口在受管工作区打开简体中文 FreeCAD，创建独立测试文档。桥接在软件进程里应答 YA 的会话挑战，核对活动文档后再操作。
3. 前台验收应同时确认软件、模型和 YA 可见。通过后，用 [适配器说明](../../../适配器/FreeCAD/说明.md) 的 Run 流程继续修改当前对象。另一个软件进程重开 FCStd 核对实际尺寸和实体数量。
4. 若几何任务已完成而 YA 未确认可见，先 Diagnose 核对请求状态和窗口，保留原模型。已完成的任务只复验显示，不另开建模请求。执行状态未知时不自动重试。

随包公开的是可移植的连接方法。当前软件安装、具体窗口、运行日志和用户工程由本机自行核验和保存。
