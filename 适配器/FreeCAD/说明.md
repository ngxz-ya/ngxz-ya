# 开源建模入门

只有用户选择「用开源建模」或明确选择这条 FreeCAD 路线时才执行。指定其他软件时走包内通用接入指南。[实测连接方法和排错](../../经验库/槽/freecad/连接方法.md)随包公开。

从下载包根目录运行：

    powershell -NoProfile -ExecutionPolicy Bypass -File .\启动.ps1 -Software FreeCAD -OpenCad

Windows x64。首次从官方获取固定版本的便携程序与便携解压工具，逐个核对 SHA256，存到当前工作区的 OpenCAD 目录。首次启动默认显示 FreeCAD 官方简体中文界面。语言可在软件偏好中更改，配置仅保存在本工作区。参考件会在新的可见文档创建，保存原生 FCStd 并在另一软件进程测量。已经接通同一个前台会话时会显示该会话供继续操作。

当前适配器支持该独立文档内的一个参数化实体长方体。用户说出长、宽、高时，Agent 用工作区的连接软件.ps1 -Software FreeCAD -Action Run -TaskFile 本次任务.json。任务中 parameters 包含 length、width、height，单位 mm，取值 1–1000；steps 用 set_box，expected 分别核验三个尺寸及 body_count=1。可为任务填写 keywords（例如长方体、方块、尺寸修改），以后用 exp_search slot=freecad q=长方体 找到实测方法。旧版首连记录可用「开源建模参考件」查找。可从 OpenCAD 本次会话的 first-task.json 复制结构，新建任务文件并填入当前目标。最终状态按 YA 记录及原始回执报告。

部署后可在工作区通过本包命令执行 `skill_search q=FreeCAD`，再用 `skill_get id=NGXZ-REF-FREECAD-BOX` 读取随包工法。参考卡不写入用户经验库，成功与否按自己的任务回执记录。

失败时保留 OpenCAD 的下载、启动和登记证据，运行工作区连接软件.ps1 的 Diagnose 进一步检查。首次下载约 400 MB，解压后约 2.3 GB。运行时间取决于网络与磁盘速度。已有另一款软件的活动连接时，可指定一个新的 -Workspace 来独立使用本路线。
