# 安装与卸载

普通使用从下载根运行 启动.ps1 -Software "软件名称"，工具自动部署到长期工作区并安装本包组件。以下维护命令只在部署后的工作区内，用Windows PowerShell 5.1执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\安装卸载\安装.ps1" -PackageOnly
powershell -NoProfile -ExecutionPolicy Bypass -File ".\YA插件\本包命令.ps1" self_check
powershell -NoProfile -ExecutionPolicy Bypass -File ".\YA插件\本包命令.ps1" overview
powershell -NoProfile -ExecutionPolicy Bypass -File ".\安装卸载\卸载.ps1" -PackageOnly
```

包隔离安装目录是本机LOCALAPPDATA/YALink/packages/包路径标识（非ASCII用户路径时使用ProgramData）。它复制四个运行时脚本及本包指针，核对本包经验库；不改用户环境变量、不覆盖旧全局安装、不安装机械软件。安装日志位于该目录的install.log。

self_check的RESULT:OK只说明包结构、槽与教练文件可用，不代表软件接通。运行命令统一经本包命令.ps1，不要沿用另一解压包的安装指针。

卸载只删除本包安装记录允许的脚本和指针文件，经验、模型、原始事件和其他包保留。不递归删除未知文件。不要为了测试卸掉用户正在使用的旧式全局安装。

当前隔离包会拒绝不带PackageOnly的装卸命令，防止误写全局安装。旧式全局安装的内部实现暂留源码用于兼容审查，不能把它当作当前允许的运行方式；历史全局回归脚本也不作为本轮隔离验收入口。

所有PowerShell源码保持UTF-8 BOM。File.Replace或本机工作目录被权限限制时明确报错，需取得正常权限；不绕过或把错误改成成功。崩溃或超时导致operation被阻断时，先用统一入口Diagnose，不自行卸装来清掉证据。
