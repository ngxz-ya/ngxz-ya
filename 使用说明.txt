ngxz-ya｜和 Agent 聊天，操作机械软件

把下面两行发给能操作你电脑的 Agent。

https://github.com/ngxz-ya/ngxz-ya
从 GitHub 下载这个包到新目录，再连接我本机的〈软件名〉

想先用开源软件，就把第二行换成「从 GitHub 下载这个包到新目录，再用开源建模做一个长方体」。
包里带 FreeCAD 的连接方案和实测工法。Agent 会按需取得官方便携版，以简体中文打开。连好后，你可以继续说「把长度改成 35 毫米」。

Agent 先下载，再按包里的流程查你点名的软件、找连接方法。连接验收通过后，软件窗口和 YA 面板会保持打开。操作完成后，Agent 会读回真实结果，验证通过才保存方法。其他软件能否连接，要看版本和可用接口。

换 Agent 时告诉它继续用原工作区。里面有以前的连接方法、操作经验和成果。类似任务可以先借鉴旧方法，再核对这次结果。经验越积越多，以后也能给具备本机工具能力的本地模型用。纯本地模型独立做完一整套任务还待实测。

我们会持续更新。更多开源机械软件接入并实测通过后，会把适用版本、能做的操作和可分享的连接方法与经验随包提供。
