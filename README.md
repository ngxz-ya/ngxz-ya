# ngxz-ya｜通用机械软件 AI 连接与经验复用工具包

让 Agent 边做事，边留下下次用得上的方法。

ngxz-ya 给 AI Agent 和机械软件搭一座桥。连接并验收通过后，你可以继续在对话里说「做一个长方体」「把长度改成 35 毫米」，Agent 在同一个软件窗口里执行，读回结果确认改对了，再把验证过的方法存到本机。

## 一句话开始

把下面这句话发给能在 Windows 读取本机文件、执行命令的 Agent。

```text
https://github.com/ngxz-ya/ngxz-ya 连接我本机的〈软件名〉
```

把〈软件名〉换成你要连接的软件。Agent 会先下载仓库，按 [AGENTS.md](AGENTS.md) 建立工作区、准备经验库和 YA 面板，再检查你点名的软件。包内找不到合适方法时，它会按 [通用接入指南](连接教练/通用接入指南.md) 查找开源连接方案或 MCP，核对实际版本和接口。

还没装机械软件，可以把「连接我本机的〈软件名〉」换成「用开源建模做一个长方体」。包里已有 [FreeCAD 的实测连接方法](经验库/槽/freecad/连接方法.md) 和可检索的长方体工法。Agent 会按需获取官方便携版，以简体中文打开。这个示例已验证同窗口修改尺寸和独立重开测量。

## 做过的事，下次接着用

- **有用的方法存下来。** 经验里有当时的条件、参数、步骤、验证结果和适用范围。遇到类似任务，先查旧方法，再确认这次能不能用。不同软件的经验分开存放。
- **换 Agent 也能接着做。** 工具不绑定某家 AI。新 Agent 回到同一个工作区，就能读取以前的连接方法、操作经验和成果。程序更新时，经验和模型仍留在你电脑上。
- **工作进度看得见。** YA 面板显示连接状态、任务进度和经验记录。有真实来源时显示 Token 用量，否则显示「未统计」。
- **经验可以留给本地模型。** 能调用本机工具的模型也可以读这些经验和调用同一套接口。完全由本地模型独立完成整套任务，仍待实测。

## 怎样才算连上

软件窗口和 YA 面板都可见，Agent 能在同一个窗口里操作并读回结果，才算前台连接成功。只完成后台任务时，Agent 会单独报告后台结果。其他软件能否连上、能做哪些事，取决于实际版本、可用接口和实测结果。

## 持续更新

我们会逐步加入更多开源机械软件的连接和操作能力。每款软件实测通过后，公开适用版本、已验证的操作、可公开的连接方案和工法。
