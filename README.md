# ngxz-ya｜用对话操作机械软件

把 GitHub 地址和一句话发给能在 Windows 读取文件、执行命令的 Agent。

```text
https://github.com/ngxz-ya/ngxz-ya
连接我本机的〈软件名〉
```

想直接试开源软件，可以把第二行换成「用开源建模，做一个长方体」。

## 包里已经有什么

- **FreeCAD 入门**。这是开源的参数化机械建模软件。包内带 [已实测的连接方案](经验库/槽/freecad/连接方法.md) 和可检索的长方体工法。Agent 按需获取官方便携版，以简体中文打开。已验证在同一窗口修改长方体，并独立读回尺寸。其他功能和开源软件逐项实测后再加入。
- **连接自己的软件**。Agent 先用已有会话或已审查的方法，再找合适的接口。能否连接取决于具体软件、版本和接口。
- **YA 和本机经验**。看得到连接、任务和验证结果。验证通过的方法按软件分开保存。换 Agent 时继续用原工作区，先查旧经验，再执行新任务。

首次启动默认使用桌面的 `ngxz-ya` 工作区。程序升级保留经验和成果。没有真实用量来源时，YA 显示「未统计」。

Agent 从 [AGENTS.md](AGENTS.md) 开始。用户可看 [简明使用说明](使用说明.txt)，接入其他软件时参照 [通用接入指南](连接教练/通用接入指南.md)。
