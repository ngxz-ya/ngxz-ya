# ngxz-ya｜通用机械软件 AI 连接与经验复用工具包

让 Agent 边做事，边留下下次用得上的方法。

> **Agent 必读（先于一切）：先读 [AGENTS.md](AGENTS.md) 文首「首连最短路径」（不超过一页），细节按其中指针查阅，不要整本通读。** 任何 Agent 一律使用桌面固定路径 `ngxz-ya`（DesktopDirectory\ngxz-ya）：**已有包就用，没有才下载到这里**；禁止枚举桌面其他内容。包根即工作区，不再生成 ngxz-ya-ws。出厂零连接经验。一条命令：`.\一键连接.ps1 -Software "<软件名>"`。每个大步骤前运行 `连接教练\越界路径审计.ps1`，命中即本轮失败并停止。禁止列举用户主目录、桌面、文档、下载、盘符根、`Program Files` 根，禁止读 `.gitconfig` 和其他项目。

ngxz-ya 给 AI Agent 和机械软件搭一座桥。连接并验收通过后，你可以继续在对话里说「做一个长方体」「把长度改成 35 毫米」，Agent 在同一个软件窗口里执行，读回结果确认改对了，再把验证过的方法存到本机。

## 一句话开始

把下面这句话发给能在 Windows 读取本机文件、执行命令的 Agent。

```text
https://github.com/ngxz-ya/ngxz-ya 连接我本机的〈软件名〉
```

把〈软件名〉换成你要连接的软件。Agent 按 [AGENTS.md](AGENTS.md) 落位：起始目录已有包和经验就直接用，不要重新下载；没有本包才下载仓库。然后建立工作区、准备经验库和 YA 面板，再检查你点名的软件。包内找不到合适方法时，它会按 [通用接入指南](连接教练/通用接入指南.md) 查找开源连接方案或 MCP，核对实际版本和接口。

日常使用只留桌面上的一个 `ngxz-ya` 文件夹（用户已部署的长期入口）。**一句话首连：起始目录已有本包和经验就直接用，不要重新下载；只有空的起点目录才下载解压 GitHub ZIP。不枚举桌面或用户文档找旧包**，工作区默认建在同一起点目录下的 `ngxz-ya-ws`。包里的 `工作区` 放工具、经验库和连接方法，`artifacts`（兼容旧名 `成果`）放模型和验证记录。换 Agent 或更新程序都继续用这一个目录。你不用另外建隔离包。

**连接方法一律先上网找合法开源方案**：GitHub 搜「<软件名> MCP / GUI bridge / 官方 API 名 + example」、[MCP Registry](https://registry.modelcontextprotocol.io/)、官方 API 文档；本包只提供通用脚本链（定位、启动、接口探测、编译、弹窗守护、握手、改模读回、存经验），不内置任何软件的连接实现。

## 做过的事，下次接着用

- **随包 429 张通用候选卡。** 覆盖 40 个机械工程类别（读图、建模、装配、公差、CAM、仿真等），用 `skill_search` 检索。都是候选指导（v=0），不是某软件已实测的结论，也不含任何软件的连接方法。
- **有用的方法存下来。** 经验里有当时的条件、参数、步骤、验证结果和适用范围。遇到类似任务，先查旧方法，再确认这次能不能用。不同软件的经验分开存放。
- **换 Agent 也能接着做。** 工具不绑定某家 AI。新 Agent 回到同一个工作区，就能读取以前的连接方法、操作经验和成果。程序更新时，经验和模型仍留在你电脑上。
- **工作进度看得见。** YA 面板显示连接状态、任务进度和经验记录。有真实来源时显示 Token 用量，否则显示「未统计」。
- **经验可以留给本地模型。** 能调用本机工具的模型也可以读这些经验和调用同一套接口。完全由本地模型独立完成整套任务，仍待实测。

## 怎样才算连上

软件窗口和 YA 面板都可见，Agent 能在同一个窗口里操作并读回结果，才算前台连接成功。只完成后台任务时，Agent 会单独报告后台结果。其他软件能否连上、能做哪些事，取决于实际版本、可用接口和实测结果。

## 持续更新

我们会逐步加入更多开源机械软件的连接和操作能力。每款软件实测通过后，公开适用版本、已验证的操作、可公开的连接方案和工法。
