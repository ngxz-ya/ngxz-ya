# ngxz-ya｜用对话操作机械软件

给能在 Windows 读取文件、执行命令的 Agent 发仓库地址和一句要求，后续可以继续用对话下任务。

```text
https://github.com/ngxz-ya/ngxz-ya
从 GitHub 下载这个包到新目录，再连接我本机的〈软件名〉
```

想先试开源软件，把第二行换成「从 GitHub 下载这个包到新目录，再用开源建模做一个长方体」。

## 怎么连接和操作

Agent 先从 GitHub 下载并读包内 [AGENTS.md](AGENTS.md)，再用包内入口检查你点名的软件。探测只针对目标软件的安装、版本、窗口和接口。需要查连接方法时，先读包内方案或你指定的本机工作区，再按 [通用接入指南](连接教练/通用接入指南.md) 找公开接口。已有软件能否操控，取决于实际版本和可用接口。

**FreeCAD 可以直接上手。** 包内带 [实测连接方案](经验库/槽/freecad/连接方法.md) 和可检索的长方体工法。Agent 按需获取官方便携版，以简体中文打开。已实测在同一窗口改长方体尺寸，再由独立进程重新打开模型、测量结果。连好后可以继续说「把长度改成 35 毫米」。

## 做一次，留下下次能用的方法

- **换 Agent 也能接手。** 经验和成果放在本机工作区。换 Agent 或模型时，让它回到同一工作区，读之前的连接方法、参数和验证证据，然后在适用时接着做。
- **经验越用越多。** 通过验证的任务按软件分槽，记录目标、操作步骤、参数和适用条件。新任务先找经验，再用实际结果验证。未解决的问题可以留下证据供下次排查。
- **软件和 YA 都看得见。** YA 显示连接状态、任务、经验和有真实来源的用量。没有用量来源时显示「未统计」。模型和经验默认留在本机，更新程序时继续沿用原工作区。
- **本地模型也能用同一套接口。** 能读写本机文件、执行命令和调用工具的本地模型，可以用这些经验辅助操作已适配的软件。积累足够的实测方法后，可以减少重复摸索。纯本地模型从理解指令到独立完成整套任务，仍待实机盲测。
